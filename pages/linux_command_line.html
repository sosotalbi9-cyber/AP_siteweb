Mémento des commandes Linux

Commande Description Options courantes Exemple d'utilisation
ls Liste les fichiers et dossiers
  • -l affichage détaillé
  • -a montre les fichiers cachés
  • -h tailles lisibles (avec -l)
 ls -l
cd Change de répertoire
  • .. dossier parent
  • ~ dossier personnel
  • - dossier précédent
 cd /home/user
pwd Affiche le répertoire dans lequel on se trouve
  • -P chemin réel, sans lien symbolique
 pwd
mkdir Crée un nouveau répertoire
  • -p crée aussi les dossiers parents
  • -v affiche ce qui est créé
 mkdir exemple
touch Crée un fichier vide
  • -c ne crée pas le fichier s'il existe pas
 touch readme.md
cp Copie un fichier ou un répertoire
  • -r copie un dossier et son contenu
  • -i demande avant d'écraser
  • -v affiche les fichiers copiés
 cp exemple1.txt exemple2.txt
mv Déplace ou renomme un fichier
  • -i demande avant d'écraser
  • -n n'écrase jamais
  • -v affiche ce qui est déplacé
 mv ancien.txt nouveau.txt
rm Supprime un fichier
  • -r supprime un dossier et son contenu
  • -i demande confirmation
  • -f force, sans rien demander
 rm fichier.txt
rmdir Supprime un répertoire vide
  • -p supprime aussi les parents vides
  • -v affiche ce qui est supprimé
 rmdir exemple
cat Affiche le contenu d'un fichier
  • -n numérote les lignes
 cat fichier.txt
echo Affiche un texte
  • -e interprète les \n (retour à la ligne)
  • -n pas de retour à la ligne final
 echo "Bonjour"
nano Modifie un fichier dans le terminal
  • Ctrl+O enregistre
  • Ctrl+X quitte
 nano fichier.txt
clear Efface l'écran du terminal
  • Ctrl+L même effet, au clavier
 clear
whoami Affiche le nom de l'utilisateur connecté Aucune option courante whoami
sudo Exécute une commande en administrateur
  • -i ouvre un terminal administrateur
  • -u exécute en tant qu'un autre utilisateur
 sudo apt update
chmod Modifie les permissions d'un fichier ou répertoire
  • -R applique aussi au contenu du dossier
  • +x rend le fichier exécutable
  • -w retire le droit d'écriture
 chmod 755 script.sh
chown Change le propriétaire et le groupe
  • -R applique aussi au contenu du dossier
  • -v affiche les changements
 chown root:root fichier.txt
ip Affiche ou manipule le routage, les interfaces et les sous-réseaux
  • a adresses IP
  • r table de routage
  • link interfaces réseau
  • -br affichage court
 ip a
ping Teste la connexion avec une machine
  • -c nombre de paquets à envoyer
  • -i délai entre deux paquets (en secondes)
 ping -c 4 8.8.8.8
man Affiche le manuel d'une commande
  • -k cherche par mot-clé
  • q quitte le manuel
 man ls
history Affiche les dernières commandes tapées
  • 10 affiche les 10 dernières
  • -c efface l'historique
 history
